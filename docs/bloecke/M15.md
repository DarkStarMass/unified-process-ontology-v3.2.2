# M15 — Aktionsprototypen

Status: abgenommen (C20), 2026-10-17

## Befund

Neun zufällige Aktionsvektoren entschieden im Stresstest nie. Drei Umgebungsstufen sind mit der heutigen Sensorik trennbar.

## Warum

Eine Aktion bekommt eine Bedeutung nur durch eine nachprüfbare Eigenschaft der Eingabe. Die übrigen Namen bleiben ungebunden.
